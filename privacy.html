Privacy Policy

Hermes — personal automation client. Last updated: 17 September 2026.

This policy describes how Hermes (the "Application") accesses and handles Google user data. The Application is a private, non-commercial personal tool operated by a single individual (the "Owner") — the same person whose Google account it is authorised for.

1. What data the Application accesses

With the Owner's explicit consent, the Application requests access to the following data in the Owner's own Google account:

  • Gmail (gmail.readonly, gmail.modify, gmail.send) — reading, searching, labelling and sending the Owner's email at the Owner's request
  • Google Calendar (calendar) — reading, creating and deleting events in the Owner's calendars
  • Google Drive (drive) — listing, reading, uploading, sharing and removing files in the Owner's Drive
  • Google Sheets (spreadsheets) and Google Docs (documents) — reading and editing the Owner's spreadsheets and documents
  • Google Contacts (contacts.readonly) — reading the Owner's contact names and addresses

No other Google data is accessed. The Application does not access data belonging to anyone other than the Owner.

2. How the data is used

Data is used solely to carry out tasks the Owner asks for in a conversation with the Application — for example, summarising unread messages, creating a calendar event, or writing a note to a file. Processing happens locally on the Owner's own equipment and infrastructure. The data is never used for advertising, profiling, or any purpose other than the Owner's direct request.

3. Storage and security

  • Content copied from Google is kept only as long as needed to complete a request and is stored on infrastructure controlled by the Owner.
  • The only long-lived credential stored is an OAuth refresh token, kept on the Owner's own server with restricted file permissions.
  • The Owner can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token.

4. Sharing

Google user data is not sold, rented, transferred or disclosed to any third party. No advertising networks, analytics services or data brokers receive it. Data is not used to train machine-learning models and is not used to determine creditworthiness or for lending purposes.

5. Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Google user data is retained only for as long as it is needed for the purposes described above. The Owner may request deletion of any stored data at any time by writing to the contact address below; such requests are fulfilled without undue delay. Revoking the Application's access in the Google Account settings stops all further access immediately.

7. Children

The Application is a private tool and is not directed to, marketed to, or intended for use by children.

8. Changes to this policy

Any changes to this policy will be published on this page with an updated revision date.
